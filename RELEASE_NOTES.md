codex-remote 0.2.1

Updated shared-host references to Codex Command Extensions. Added official-directory draft ZIP packaging, listing metadata, icons, public data/license information and proposed review cases.

Install the built `.tgz` for normal use. The `-directory.zip` asset is a draft for the OpenAI submission portal, not an approved or published listing. See [submission preparation](https://github.com/Cheaux/codex-remote/blob/main/submission/README.md) for prerequisites and remaining account/review steps.

Requires Node 24+ and compatible official Codex interfaces. The command host requires Python 3 on Linux/macOS; Windows terminal support remains unavailable.
